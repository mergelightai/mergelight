# Mergelight

AI code review that runs on the Claude or ChatGPT plan you already pay for.

Mergelight reviews every pull request with your own subscription, so there is no per-review bill. It runs in your own GitHub Actions, and your code and AI login never reach Mergelight.

- **Turn it on:** [mergelight.dev/setup](https://mergelight.dev/setup), or read the [GitHub Action guide](docs/github-action.md).
- **Handle findings in your coding agent:** `npx @mergelight/cli init`, or read [Mergelight in your coding agent](docs/agents.md).
- **The engine and CLI:** [packages/mergelight](packages/mergelight).
