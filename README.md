# Mergelight

AI code review that runs on the Claude or ChatGPT plan you already pay for.

Mergelight reviews every pull request with your own subscription, so there is no per-review bill. The review engine is open source and self-hostable. A hosted version with a dashboard and review memory is on the way at [mergelight.dev](https://mergelight.dev).

**Status:** early. There's nothing to install yet. Watch this repo to follow along.
